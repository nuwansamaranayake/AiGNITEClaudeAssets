Style: {{STYLE_DESCRIPTOR}}

NOTES:
- Lead with the style descriptor. Flux 2 Pro weights the first phrase heavily.
- Three style adjectives is plenty.
- For a series, reuse the style block verbatim across prompts.

EXAMPLE (AEO insight page on query intent):
Style: flat vector illustration, isometric, gradient mesh
Subject: a single beam of light entering a glass prism and splitting into colored beams labeled with AI engine names (ChatGPT, Claude, Perplexity, Gemini)
Key visual element: glowing knowledge graph nodes connected to each beam
Color palette: indigo, emerald, soft cream background
Composition: prism centered, beams fanning to the right, labels in clean sans-serif
Mood: clarity and curiosity
